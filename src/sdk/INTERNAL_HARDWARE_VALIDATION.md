# SDK 封装后硬件联调验收清单

**用途**：阶段 1.1 在保留 **WebSerial 真实下发** 的前提下，对 `sdk` 收口后的绑定页、编排页及相关能力做现场/台架验证。

**前置**：串口已连接、舵机供电正常、工程中 `configs`（舵机启用、方向、行程、机械零位等）与实际硬件一致。

**填写说明**：逐项勾选 `- [ ]` → `- [x]`，必要时在备注列记录舵机号、PWM 读出值或异常现象。
