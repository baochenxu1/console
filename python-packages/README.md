# Python 舵机 API（SC / ST / RJ 独立包）

| 包目录 | 协议 | pip / import |
|--------|------|----------------|
| `scservo/` | 飞特 SC | `scservo` / `ScServoClient` |
| `stservo/` | 飞特 ST | `stservo` / `StServoClient` |
| `rjsbus/` | 锐捷 RJ_SBUS | `rjsbus` / `RjSbusClient` |

对外发布压缩包见 `releases/` 与 GitHub Release `servo-python-apis-v1.0.0`。

旧目录 `feetech-scservo/`、`rj-sbus/` 保留作兼容；新集成请用上面三个独立包。
